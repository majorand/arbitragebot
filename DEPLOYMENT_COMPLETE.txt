🔄 API REFERENCE
================

GET /mode
  Response: {"mode": "paper" | "live"}

POST /mode
  Body: {"mode": "paper" | "live"}
  Response: {"mode": "..."}

GET /odds
  Response: [{"event": "...", "edge": 3.2, "venues": "..."}, ...]

POST /trades
  Body: {
    "market_id": "xyz",
    "side": "yes" | "no",
    "stake": 100,
    "exchange": "kalshi"
  }
  Response: {"trade_id": "...", "status": "pending", ...}

GET /trades
  Response: [{"trade_id": "...", "status": "filled", ...}, ...]

GET /positions
  Response: [{"instrument": "...", "size": 100, ...}, ...]

GET /metrics
  Response: {"total_trades": 42, "cash_balance": 1500, ...}

WS /ws
  Real-time updates (positions, trades, opportunities)

❓ TROUBLESHOOTING
==================

Q: Backend won't start
A: Check Python 3.11+, verify pip install -r requirements.txt

Q: Frontend shows blank page
A: Clear cache (Ctrl+Shift+Del), run npm run build

Q: API connection fails
A: Verify backend on port 8000, check .env.local

Q: No opportunities showing
A: Check Kalshi API key, wait 10 seconds for data fetch

Q: WebSocket connection error
A: Verify /ws endpoint, check CORS settings

See DEPLOYMENT.md for detailed troubleshooting.
