CONFIGURATION REQUIRED
══════════════════════

Before first run, create: web/backend/backend.env

Required credentials:
  SUPABASE_URL=https://your-project.supabase.co
  SUPABASE_KEY=your_supabase_key_here
  KALSHI_API=https://api.kalshi.com
  KALSHI_API_KEY=your_kalshi_api_key_here
  TRADING_MODE=paper        # IMPORTANT: Start with 'paper'!
  FRONTEND_ORIGINS=http://localhost:3000

Where to get credentials:
  • Supabase: https://app.supabase.com → API Keys
  • Kalshi: https://kalshi.com/developers → API Dashboard
  • Keep TRADING_MODE=paper until thoroughly tested
