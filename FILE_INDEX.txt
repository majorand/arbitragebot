API ENDPOINTS
=============

GET /mode
  Returns current mode: {"mode": "paper"} or {"mode": "live"}

POST /mode
  Change mode: {"mode": "paper"} or {"mode": "live"}

GET /odds
  Returns opportunities: [{"event": "...", "edge": 3.2, ...}]

POST /trades
  Execute trade: {"market_id": "...", "side": "yes", "stake": 100, ...}

GET /trades
  Get history: [{"trade_id": "...", "status": "filled", ...}]

GET /positions
  Get positions: [{"instrument": "...", "size": 100, ...}]

GET /metrics
  Get stats: {"total_trades": 42, "cash_balance": 1500, ...}

WS /ws
  WebSocket for real-time updates

Full docs: http://localhost:8000/docs (Swagger UI)

CONFIGURATION FILES
===================

backend.env (REQUIRED - Fill before running!)
  SUPABASE_URL=https://your-project.supabase.co
  SUPABASE_KEY=your_supabase_key
  KALSHI_API=https://api.kalshi.com
  KALSHI_API_KEY=your_kalshi_api_key
  TRADING_MODE=paper          # Start with 'paper'!
  FRONTEND_ORIGINS=http://localhost:3000

.env.local (Frontend config)
  NEXT_PUBLIC_API_BASE_URL=http://localhost:8000

config/strategy.yaml (Optional: Tune strategy)
  min_edge_percent: 2.5
  min_liquidity: 1000
  max_exposure: 5000
  max_stake_per_trade: 500
  venues: [kalshi, draftkings, fanduel]
  sports: [nfl, nba, mlb, nhl]

TROUBLESHOOTING REFERENCE
=========================

Backend Won't Start:
  Check: Is Python 3.11+ installed?
  Check: Is uvicorn installed? pip list | grep uvicorn
  Check: Is port 8000 available? lsof -i :8000
  Check: Are env vars set? echo $SUPABASE_URL

Frontend Won't Start:
  Check: Is Node 18+ installed? node --version
  Check: npm install completed? npm list next
  Check: Port 3000 available? lsof -i :3000
  Check: .env.local exists? ls web/frontend/.env.local

No Data Showing:
  Check: Kalshi API key valid? test in /docs
  Check: Supabase connected? web/backend/config.py
  Check: Wait 10 seconds for data fetch
  Check: Browser console for errors (F12)

API Connection Fails:
  Check: Backend running? curl http://localhost:8000/docs
  Check: Frontend .env.local correct? cat web/frontend/.env.local
  Check: CORS enabled? web/backend/app.py
  Check: Firewall blocking? Check network logs

See DEPLOYMENT.md for detailed troubleshooting
